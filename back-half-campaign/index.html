최종 목표 95/100

27/30은 코드 선별 기준입니다. 최종 95/100은 앞으로 달성할 목표이며 현재 측정된 성공률이 아닙니다. 같은 handoff를 반복한 파일럿은 독립된 30회 검증으로 계산하지 않습니다.

학습 전 시작 상태도 검증합니다.

시작할 때 이미 잡고 있어야 하는 물체가 떨어지거나, 접근·객체 매핑이 잘못된 경우를 정밀 접촉 정책의 실패로 넘기지 않습니다. 선행 잡기와 handoff의 실제 물리 상태를 먼저 확인한 뒤 코드 수정과 학습을 구분합니다.

02 / ONLY WHEN NEEDED

교사는 작은 구간을 잘하게 만듭니다.

실제 코드 실행→handoff bank→BC → PPO

코드가 넘겨주는 다양한 상태에서 학습

코드로 접근한 실제 상태를 모아 bank를 만듭니다. 매 rollout마다 긴 접근을 다시 실행하지 않고, 이 상태에서 접촉 학습을 반복합니다.

  • 정상 handoff, 회복 가능한 오차, 물리적으로 유효한 랜덤화를 섞습니다.
  • 교사는 물체 자세·속도·접촉 등 privileged 정보를 받습니다.
  • 단계 선행조건과 1회 보상에 구간 전용 보상을 더합니다.

BC 원본에 assisted grasp가 쓰였는지 표시합니다. 원본 시연이 있다는 사실을 물리 성공의 증거로 취급하지 않습니다. BC만으로 실패하더라도 유효한 데이터라면 PPO 초기화로 활용할 수 있습니다.

학습 부위

필요한 관절만 활성화

한 팔 8D → 필요한 경우 팔+몸통 12D → 양손 협업·전신이 필요할 때 확장합니다. 바깥 제어 계약은 23D로 맞추고 나머지는 코드로 유지합니다.

새 실험의 검증

수치 + 실제 영상 + 유지 검사

성공·실패·최신 영상을 확인하고 원인에 맞춰 수정합니다. 급상승, 접시 밀기, 과도한 상체 움직임, 미끄러짐도 따로 기록합니다. 성공 후 5초 유지 영상도 확인합니다.

이 단계는 teacher 학습까지입니다. VLA/student distillation은 이후 단계로 남깁니다. 환경이 제공하지 않는 센서나 impedance 제어가 이미 구현된 것처럼 표시하지 않습니다.

04 / SMALL, TRACEABLE ARCHIVE

기존 모델은 다섯 개만 남겼습니다.

4.75 GiB 정리 완료
원본 데이터·시뮬레이터 환경 보존

보관 역할모델확인된 결과남겨둔 이유

‘성공사례 보관’은 전체 태스크 숙달을 뜻하지 않습니다. 서로 다른 관측·완료 판정의 성공률을 합쳐 비교하지 않습니다. 현재 모델은 전체 optimizer 상태와 BC 재개 의존성까지 유지했습니다.

앞으로의 보관 규칙

다섯 개는 이번 기존 실험 정리의 결과입니다. 새 50개 태스크에서 검증된 교사는 별도로 보존해야 합니다. 각 학습 실험은 최신·최고·실패 대표만 남기고, 검증 통과한 최종 교사는 구간별 1개로 등록하는 것을 운영 규칙으로 삼습니다.
